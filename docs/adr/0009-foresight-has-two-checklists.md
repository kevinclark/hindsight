# 9. Foresight has two checklists: the queue and the start of practice

Status: accepted, 2026-10-23

## Decision

One engine, two checklists. **In the queue at an event:** about seven items, the most critical first, done then
confirmed; each system gets Go, Go with deferrals (named) or No-go, as in a go/no-go poll. **At the start of a practice
session:** a longer list read and done in order (battery, CAN, cameras, zeros), ending in "ready to drive" or what is
left, with no Go verdict.

## Why

Checklist research for flight decks: critical items first, because interruptions skip the later ones; short lists;
read-do for a setup pass and do-confirm for a gate (Degani & Wiener, NASA CR-177549, 1990).
